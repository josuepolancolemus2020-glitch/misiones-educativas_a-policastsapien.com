🎯 Objetivos de Aprendizaje

  1. Explicar el ciclo del robot: leer sensores → decidir → mover actuadores → repetir.
  2. Usar las instrucciones de movimiento (avanzar, girar) y la de espera.
  3. Escribir condicionales con sensores: SI… ENTONCES… SINO…
  4. Usar bucles («repite N veces», «repite hasta…», «repite mientras…»).
  5. Usar variables para contar (giros, objetos recogidos).
  6. Escribir el programa en pseudocódigo y depurarlo paso a paso.

🔁 1. El ciclo del robot: un bucle que nunca para

Mientras un robot está encendido repite siempre lo mismo: lee sus sensores, decide con su programa, mueve sus actuadores y vuelve a empezar. Ese ciclo es un bucle infinito que se repite muchas veces por segundo.

💡 Truco: ante cualquier programa de robot pregúntate tres cosas: ¿qué lee?, ¿qué decide? y ¿qué hace? Si falta alguna, el robot va a fallar.

📡🧠⚙️ Mini-demostración: los tres pasos del ciclo

El programa une los tres pasos y luego los repite
📡1. Leer sensores¿Hay pared adelante? ¿Veo la línea negra? ¿Está seca la tierra?
🧠2. DecidirSI pasa esto, ENTONCES haz aquello, SINO haz lo otro.
⚙️3. Mover actuadoresAvanza, gira, recoge, abre el agua.

🔄 Y vuelve al paso 1: repetir es el cuarto paso invisible del ciclo.

❓ 3. Condicionales con sensores

Un condicional es el bloque SI… ENTONCES… SINO…. El robot lee un sensor y elige una de las dos ramas. Así el mismo programa sirve aunque las cosas cambien de lugar:

# Sensor de pared (obstáculo) SI hay pared adelante ENTONCES GIRA DERECHA SINO AVANZA # Sensor de línea (color del piso) SI hay línea negra adelante ENTONCES AVANZA SINO GIRA DERECHA
🧱 Sensor de pared / obstáculoMira la casilla de adelante: si hay un cajón o el borde del patio, responde SÍ. Sirve para esquivar sin chocar.
⬛ Sensor de línea / colorDistingue el negro de la línea pintada del piso claro. Sirve para seguir el camino del pasillo.
🎯 Regla de oro: todo condicional debe decir también qué hacer cuando la respuesta es NO (la rama SINO). Si falta, el robot se queda «pensando» o hace algo inesperado.

📝 5. Pseudocódigo y 🐞 depuración

El pseudocódigo es el programa escrito en español claro y numerado, antes de cargarlo al robot. Depurar es probar el programa paso a paso, encontrar la instrucción equivocada (el bug) y corregirla. Recuerda: el robot hace lo que dice el programa, no lo que uno quiso decir.

# Robot regador del huerto escolar 🌱 1. plantas = 0 2. REPITE 10 VECES: 3. AVANZA 4. SI el sensor de humedad dice «tierra seca» ENTONCES abre la válvula 5. SINO sigue adelante 6. plantas = plantas + 1 7. DETENTE y avisa cuántas plantas regó

🎲 6. Actividades desconectadas (sin computadora)

  • 🧵 El laberinto de cinta: con cinta adhesiva marquen en el piso del aula una cuadrícula de 5×5 y peguen una línea negra y algunos cajones (cajas o mochilas). Un compañero hace de robot (¡solo obedece instrucciones exactas!) y otro de programador. Luego cambian de papel.
  • 🃏 Tarjetas de flechas: recorten tarjetas con ▲ AVANZA, ↪ GIRA DER., ↩ GIRA IZQ., ⏳ ESPERA y 🎯 DETENTE. Armen el programa completo sobre la mesa antes de ejecutarlo: el «robot» solo se mueve cuando el programador levanta una tarjeta a la vez, en orden.
  • ✏️ Traza el recorrido en papel: usa la cuadrícula de abajo. Marca con una X la casilla donde queda el robot después de cada instrucción y escribe la coordenada (A1…E5). Compara con lo que hizo el «robot» humano: la primera diferencia es el bug.
  • 💧 El pseudocódigo del robot regador: escribe en tu cuaderno, numerado, el programa de un robot que riegue el huerto escolar. Debe llevar un bucle, un condicional con sensor, una variable contadora y terminar con DETENTE.
