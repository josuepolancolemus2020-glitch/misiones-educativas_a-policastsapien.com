🔁 El ciclo del robot: un bucle que nunca para

Un robot encendido hace siempre lo mismo, una y otra vez: lee sus sensores, decide con su programa, mueve sus actuadores y vuelve a empezar. Ese ciclo es un bucle infinito mientras el robot tenga batería.

📡 1. Leer sensores
¿Hay pared adelante? ¿Veo la línea negra? ¿Está seca la tierra?
🧠 2. Decidir
El programa elige: SI pasa esto, ENTONCES haz aquello, SINO haz lo otro
⚙️ 3. Mover actuadores
Los motores avanzan, giran, recogen o abren el agua
🔄 4. Repetir
El ciclo vuelve al paso 1 muchas veces por segundo
💡
Clave de esta misión: en la 💻 Ruta del Código aprendiste instrucciones, condicionales, bucles y variables. Aquí los usas todos juntos para mover un robot que además lee sensores.

👣 Las instrucciones de movimiento

El programa del robot se arma con instrucciones exactas. En nuestro simulador son estas cinco:

👣 AVANZA
Se mueve UNA casilla hacia donde está mirando
↪️ GIRA DERECHA
Cambia el rumbo, pero NO cambia de casilla
↩️ GIRA IZQUIERDA
Cambia el rumbo al otro lado, tampoco se mueve
⏳ ESPERA
Deja pasar el tiempo sin hacer nada más
🎯 DETENTE
Instrucción final: el robot se queda quieto en la meta
⚠️
Error clásico: creer que GIRA también avanza. Girar cuatro veces deja al robot exactamente donde estaba, solo que mareado. 😵

❓ Condicionales con sensores: el robot decide solo

Un condicional es un bloque SI… ENTONCES… SINO. El robot lee un sensor y, según la respuesta, ejecuta una rama u otra. Así el mismo programa sirve aunque las cosas cambien de lugar:

# Sensor de pared (obstáculo) SI hay pared adelante ENTONCES GIRA DERECHA SINO AVANZA # Sensor de línea (color del piso) SI hay línea negra adelante ENTONCES AVANZA SINO GIRA DERECHA

🧱 Sensor de pared / obstáculo

Mira la casilla de adelante: si hay un cajón o el borde del patio, responde SÍ. Sirve para esquivar sin chocar.

⬛ Sensor de línea / color

Distingue el negro de la línea pintada del piso claro. Sirve para que el robot siga el camino del pasillo.

🔄 Bucles y 📦 variables

Si el robot debe repetir lo mismo, no escribas la instrucción diez veces: usa un bucle. Y si necesita recordar un número (cuántas veces giró, cuántas botellas recogió), usa una variable.

Bloque ¿Para qué sirve? Ejemplo en el robot
🔄 REPITE N VECESHacer lo mismo un número exacto de vecesREPITE 6 VECES: AVANZA
🔄 REPITE HASTA…Repetir hasta que se cumpla algoREPITE HASTA llegar a la meta
🔄 REPITE MIENTRAS…Repetir mientras el sensor diga que síREPITE MIENTRAS no haya obstáculo: AVANZA
📦 VARIABLEGuardar un número con nombreobjetos = objetos + 1
🐞
¡Cuidado con el bucle infinito! Todo bucle necesita una forma de terminar. «REPITE PARA SIEMPRE: AVANZA» hace que el robot se salga del patio.

📝 Pseudocódigo: piensa antes de cargar el programa

El pseudocódigo es el programa escrito en español claro y numerado, antes de «cargarlo» al robot. Sirve para pensar el camino y, después, para comparar lo que el robot hizo con lo que debía hacer.

# Robot regador del huerto escolar 🌱 1. plantas = 0 2. REPITE 10 VECES: 3. AVANZA 4. SI el sensor de humedad dice «tierra seca» ENTONCES abre la válvula 5. SINO sigue adelante 6. plantas = plantas + 1 7. DETENTE y avisa cuántas plantas regó
✏️
Regla del cuaderno: una instrucción por línea, numeradas y sin frases confusas. Si otra persona puede seguirlo sin preguntar nada, tu pseudocódigo está bien escrito.

⚡ Mini-quiz relámpago

1) El robot debe avanzar 7 casillas iguales. ¿Qué conviene escribir?

2) El robot chocó con un cajón. ¿Qué pasó?

🐞 Depurar: el robot hace lo que dice el programa

El robot no adivina: ejecuta literalmente cada instrucción. Si algo sale mal, casi siempre el error está en el programa, no en la máquina. A ese error se le llama bug, y a buscarlo y corregirlo, depurar.

1️⃣ Prueba paso a paso
Ejecuta una instrucción a la vez y anota dónde queda el robot
2️⃣ Compara
¿Coincide con tu pseudocódigo? La primera diferencia es el bug
3️⃣ Corrige una sola cosa
Cambia una instrucción y vuelve a probar
4️⃣ Repite
Depurar también es un bucle: probar → corregir → probar
🇭🇳
