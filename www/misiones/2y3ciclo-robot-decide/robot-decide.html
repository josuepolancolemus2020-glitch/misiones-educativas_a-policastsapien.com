Misión Condicionales: el Robot Decide

¡Haz que el robot DECIDA con SI…ENTONCES…SINO según lo que ve! 🤖🔀🚦

💻 Ruta del Código · Etapa 3 de 7 · Programación

🔀 Decidir según la situación

Todos los días tomamos decisiones según lo que pasa: SI llueve ENTONCES llevo paraguas, SINO llevo gorra. Eso es un condicional: una instrucción que hace elegir entre dos caminos según una condición. La condición siempre es una pregunta de sí o no («¿está lloviendo?»).

❓ La condición es una pregunta

«¿Está lloviendo?», «¿hay pared adelante?». Solo puede responderse SÍ o NO: nunca «tal vez».

🔀 Dos caminos, uno solo corre

Si la respuesta es SÍ, corre la rama ENTONCES. Si es NO, corre la rama SINO. ¡Nunca las dos!

☂️
Ejemplo de la vida diaria: SI está lloviendo ENTONCES llevo paraguas, SINO llevo gorra. Cambia la respuesta y cambia lo que haces… ¡pero solo haces UNA cosa!
🎮 Mini-quiz: ¿cuál de estas SÍ es una condición (pregunta de sí/no)?

🤖 SI-ENTONCES y SI-ENTONCES-SINO en el robot

Los sensores son las «preguntas» del robot: le dicen si ¿hay pared adelante? o si ¿el semáforo está en verde?. Con esa respuesta el robot decide qué rama ejecutar y cuál ignorar.

❓ Condición
La pregunta de sí/no que lee el sensor
👉 Rama ENTONCES
Lo que hace si la respuesta es SÍ
👈 Rama SINO
Lo que hace si la respuesta es NO
☝️ Solo una rama
Se ejecuta una; la otra se ignora
🌳
En el simulador: «SI HAY PARED ADELANTE → GIRA DERECHA, SINO → AVANZA». Si el robot tiene un árbol 🌳 enfrente, gira; si el camino está libre, avanza. ¡Solo pasa una cosa!
🎮 Mini-quiz: «SI hay pared → GIRA DERECHA, SINO → AVANZA». El robot NO tiene pared adelante. ¿Qué hace?

🔗 Condicionales encadenados y el orden de las preguntas

A veces el robot necesita varias preguntas seguidas: primero «¿hay pared?», después «¿el semáforo está en verde?». Son condicionales encadenados, y el orden de las preguntas puede cambiar la decisión.

🚫 Error 1: creer que corren las dos ramas

En cada condicional se ejecuta UNA sola rama: la que responde la condición. La otra se ignora por completo.

🚫 Error 2: confundir condición con acción

La condición es una pregunta («¿hay pared?»); la acción es una orden («AVANZA»). ¡No son lo mismo!

🚦 Ejemplo con semáforo
SI SEMÁFORO EN VERDE → AVANZA, SINO → ESPERA. Con luz 🟢 verde el robot cruza; con luz 🔴 roja espera hasta que cambie. 🚦

📋 La estructura de un condicional

Un condicional tiene tres partes: una condición (la pregunta) y dos ramas (qué hacer si sí y qué hacer si no). ¡Mira cómo se lee!

Condición (pregunta)Rama ENTONCES (si SÍ)Rama SINO (si NO)
¿Está lloviendo?llevo paraguas ☂️llevo gorra 🧢
¿Hay pared adelante?GIRA DERECHA ↪️AVANZA 👣
¿El semáforo está en verde?AVANZA (cruzo) 🟢ESPERA ⏳🔴
¿Llegó a la casa?ENTREGA 📬sigue avanzando 👣
🔀
Se lee así: SI (condición) ENTONCES (rama del sí) SINO (rama del no). El robot lee la respuesta de la condición y ejecuta solo una rama.
🎮 Mini-quiz: en «SI verde → AVANZA, SINO → ESPERA», con luz 🔴 roja el robot…

⚠️ Errores comunes — ¡no caigas en ellos!

🚫 Creer que corren las dos ramas

En un condicional se ejecuta UNA sola rama. Si la respuesta es SÍ, la rama SINO ni se mira.

🚫 Confundir condición con acción

«¿Hay pared?» es una pregunta (condición). «AVANZA» es una orden (acción). La condición nunca mueve al robot: solo decide.

🚫 Invertir las ramas

Si escribes «SI hay pared → AVANZA» el robot ¡choca contra el árbol! 🌳 Cuando SÍ hay pared debe GIRAR, no avanzar.

🚫 Elegir la condición equivocada

Para no chocar, la pregunta correcta es «¿hay pared adelante?», no «¿el semáforo está en verde?». ¡El sensor debe medir lo correcto!

🎮 Mini-quiz: «SI hay pared → GIRA DERECHA, SINO → AVANZA». El robot SÍ tiene pared adelante. ¿Qué hace?

🇭🇳 Condicionales en tu vida diaria

Aunque no tengas computadora, ya decides con condicionales todo el tiempo: eliges según la respuesta a una pregunta de sí o no.

☂️ La lluvia
SI llueve → paraguas, SINO → gorra
🚦 El semáforo
SI está en verde → cruzo, SINO → espero
🔥 El fogón
SI está encendido → cocino, SINO → prendo la leña
🌡️ El clima
SI hace frío → suéter, SINO → camiseta
💡
Dato clave: el robot no adivina: su sensor responde la pregunta y él ejecuta la rama que corresponde. Buenos condicionales = buenas decisiones. 🤖
