Descubren las propiedades de la igualdad:
Se puede sumar o restar el mismo número en ambos lados de una igualdad y éstos permanecen iguales.
Ejemplo: X = 8, entonces X + 4 = 8 + 4.
Ambos lados de una ecuación se pueden multiplicar por el mismo número, y éstos siguen iguales.
Ejemplo: X = 8, entonces 4X = 4 × 8.
Ambos lados de una ecuación se pueden dividir entre el mismo número distinto de cero, y éstos siguen iguales.
Ejemplo: X = 8, entonces X / 4 = 8 / 4.
